# Install

## What you need

- Minecraft **1.21.1–1.21.11** (use a mod file that matches your exact version)
- **Fabric Loader**
- **Java 21 or newer**

## Steps

1. Download the Tools & Trims file for your Minecraft version from the project's release page.
2. Install Fabric Loader for that same Minecraft version.
3. Place the downloaded mod file in your Minecraft `mods` folder.
4. Start the game using the Fabric profile.

Do not install more than one Tools & Trims version at once. This source repository does not contain downloadable mod files.
