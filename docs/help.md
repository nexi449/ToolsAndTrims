# Help

## The mod does not load

- Make sure you are launching the Fabric profile, not Vanilla or another loader.
- Check that Fabric Loader and Java 21 or newer are installed.
- Remove duplicate Tools & Trims files from the `mods` folder.

## I cannot trim a tool

- Check that the tool is a sword, pickaxe, axe, shovel, or hoe.
- Use an armor trim template and trim material available in your Minecraft version.
- Make sure the mod file matches the exact Minecraft version you are playing.

## The trim does not change my tool's stats

That is expected. Trims are visual only.
