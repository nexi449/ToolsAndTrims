# Using the mod

1. Open a smithing table.
2. Put a vanilla armor trim template in the template slot.
3. Put a supported tool in the tool slot.
4. Put a vanilla trim material in the material slot.
5. Take the trimmed tool from the result slot.

The template chooses the pattern. The material chooses the trim color. Trimming does not change damage, durability, or other tool stats.

The mod adds crafting support; trimmed tools are not separate creative-inventory items or survival drops.
